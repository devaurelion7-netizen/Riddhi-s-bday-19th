# Riddhi's 19th Birthday Celebration Website ♥

An interactive, cinematic birthday website crafted with love and memories.

## ✨ Experience Structure

1. **The Wishing Experience (`purple-theme/index.html`)**:
   - Interactive archery bow release opening animation.
   - Blossom amethyst tree growing and blooming with purple petal hearts.
   - Lettered heartfelt birthday message and photo polaroid charms.

2. **3D Depth Collage Gallery (`memories.html`)**:
   - Built with Three.js WebGL.
   - 18 curated collage slides featuring 81 photos arranged in 3D depth space.
   - Scroll-driven camera flight with smooth inertia and velocity-reactive physics.
   - Dynamic atmospheric GLSL gradient background that shifts mood palettes across slides.
   - Floating 3D and 2D purple blossom hearts.

3. **Her People — Digital Scrapbook (`friends.html`)**:
   - Interactive polaroid card grid of close friends.
   - Live auto-syncing directly with Google Forms via published CSV.
   - Detailed modal cards featuring personalized Q&A, inside jokes, and birthday wishes.
